# Wonderclean website

A static, single-page website. No build step and no dependencies.

## Files
- `index.html` : the whole site (HTML, CSS and JavaScript)
- `images/` : the before/after photos and team photo

## Host on GitHub Pages
1. Create a new repository on GitHub (for example `wonderclean`).
2. Upload everything in this folder, keeping `index.html` and `images/` at the top level of the repo.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then **Save**.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/wonderclean/`.
